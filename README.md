# Ahamed Asri — Portfolio

A modern, interactive personal portfolio for **Ahamed Asri**, a Computer Science student.

Designed as a digital space to showcase projects, technical interests, skills, and experiments — with a strong focus on clean UI, smooth interactions, and a distinctive visual identity.

🔗 **Live site:** <https://ahamedasri.dev>

---

## ✨ Features

- Fully responsive, single-page portfolio layout
- Smooth animated transitions and micro-interactions
- Component-driven architecture for easy extension
- Fast dev/build cycle powered by Vite
- Utility-first, consistent styling via Tailwind

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| UI Library | [React](https://react.dev/) — component-based UI |
| Language | [TypeScript](https://www.typescriptlang.org/) — type-safe development |
| Build Tool | [Vite](https://vitejs.dev/) — dev server and bundler |
| Styling | [Tailwind CSS](https://tailwindcss.com/) — utility-first CSS |
| Animation | [Motion](https://motion.dev/) — motion primitives for UI transitions |
| Icons | [lucide-react](https://lucide.dev/) — minimal, consistent icon set |
| Runtime | Node.js / npm — scripts, installs, builds |

## 🎨 Design Philosophy

This portfolio isn't built off a generic template — it's designed around a distinctive visual identity, deliberate typography choices, and interaction details meant to feel intentional rather than default. Motion is used sparingly to guide attention, not distract from content.
